# Código de conduta

O SIAPP é um projeto acadêmico e comunitário. Esperamos de todos que participam
(issues, pull requests, revisões, discussões):

- **Respeito** — críticas são sobre o trabalho, nunca sobre a pessoa.
- **Boa-fé** — presuma que o outro quer acertar; pergunte antes de acusar.
- **Rigor** — afirmações técnicas vêm com fonte, dado ou exemplo reproduzível.
- **Crédito** — reconheça a autoria de quem contribuiu com código ou dados.

Não são aceitos assédio, discriminação, ataques pessoais ou divulgação de dados
pessoais de terceiros. Os mantenedores podem editar ou remover contribuições e
bloquear participantes que descumpram estas regras.

Relatos: escreva para o mantenedor do projeto. Serão tratados com sigilo.
