# Segurança

O SIAPP roda no computador do usuário e só acessa o portal público REATE.
Ainda assim, se encontrar uma falha (por exemplo, um caminho de arquivo vindo do
portal que permita gravar fora da pasta do projeto), **não abra uma issue pública**.

Use **Security → Report a vulnerability** neste repositório, ou escreva para o
mantenedor. Responderemos em até 7 dias.

Versões com correção de segurança: apenas a mais recente.
