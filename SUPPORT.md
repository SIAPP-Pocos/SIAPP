# Ajuda e suporte

| Preciso de… | Onde |
|---|---|
| Instalar, atualizar ou entender as pastas | [Instalador do Windows](docs/instalador.md) e [Estrutura da pasta](docs/estrutura-da-pasta.md) |
| Saber como usar uma função | [Documentação](docs/README.md) e o menu **Ajuda** do SIAPP |
| Tirar uma dúvida | [Discussions](https://github.com/SIAPP-Pocos/SIAPP/discussions) |
| Relatar um erro | [Nova issue › Relatar erro](https://github.com/SIAPP-Pocos/SIAPP/issues/new/choose), com o texto de **Ajuda › Diagnóstico › Copiar para enviar** |
| Sugerir uma melhoria | [Nova issue › Sugerir melhoria](https://github.com/SIAPP-Pocos/SIAPP/issues/new/choose) |
| Avisar uma falha de segurança | [Política de segurança](SECURITY.md) (não abra issue pública) |

O SIAPP é mantido por uma pessoa, no tempo livre da graduação: as respostas podem levar alguns dias.
